Topic list from Week 1 to Week 5 :

*Week 1 — Searching*
- Linear Search (O(n)) — unsorted array
- Binary Search (O(n log n)) — sorted array
- Jump Search (< O(n)) — sorted array

*Week 2 — Searching + Array Problems*
- Finding duplicates count using Binary Search (O(log n)) — sorted array with duplicates
- Finding three indices i, j, k such that arr[i] + arr[j] = arr[k] — sorted array
- Counting pairs with difference equal to key K — unsorted array

*Week 3 — Sorting*
- Insertion Sort — with comparison and shift counts
- Selection Sort — with comparison and swap counts
- Detecting duplicates using sorting (O(n log n))

*Week 4 — Divide and Conquer Sorting*
- Merge Sort — with comparison and inversion counts
- Quick Sort (random pivot) — with comparison and swap counts
- Finding Kth smallest/largest element (O(n) worst case)

*Week 5 — Sorting + Two Pointer*
- Counting sort to find most frequent alphabet (O(n))
- Two-sum problem: find two elements with sum equal to key (O(n log n))
- Finding common elements in two sorted arrays (O(m+n))
